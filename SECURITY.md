# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

The security of `rust-pdf-box` is taken very seriously. If you discover a security vulnerability, please do NOT file a public issue on GitHub.

Instead, please send an email to:
**`techwastiinfotech@gmail.com`**

Please include:
- A description of the vulnerability and potential attack vectors.
- A minimal reproducible example or proof-of-concept PDF.
- The versions of `rust-pdf-box` affected.

We will acknowledge receipt within 48 hours and work with you on a coordinated disclosure timeline.
